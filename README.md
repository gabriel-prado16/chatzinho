# 💬 Chatzinho

Um chat em tempo real desenvolvido com **Node.js**, **Express** e **Socket.io**, com sistema de usuários, mensagens privadas e upload de arquivos.

---

## 🌐 Acesse o projeto
👉 https://chatzinho.onrender.com

---

## ⚡ Funcionalidades

- 🔐 Registro e login de usuários
- 💬 Chat privado em tempo real (Socket.io)
- 🖼️ Envio de arquivos/imagens
- 👥 Lista de usuários cadastrados
- 💾 Histórico de mensagens salvo localmente (JSON)
- 🌍 Aplicação online via Render
